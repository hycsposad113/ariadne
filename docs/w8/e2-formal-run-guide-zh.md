# E2 輻射分析正式執行說明（給 Founder）

E2 會用 Ladybug 篩選＋Honeybee-Radiance 驗證，比較兩個正式方案（common-compact 與 common-mixed）在 6–8 月的地面輻射量，並做 ±1 小時敏感度測試。整個流程已在資料庫副本上完整演練通過（`artifacts/w8/e2-drill/`，正式資料庫雜湊前後不變）。

平台上目前沒有 E2 的操作畫面，所以用一支互動腳本在終端機執行。腳本只呼叫正式平台 API，決策密語用隱藏輸入讀取，不顯示、不儲存、不寫進任何記錄。

## 前提

- 正式平台已更新到含 E2 接線的版本（Commander 上線時會用新的 E2 參數重啟 8795）。
- 你手邊有決策密語。

## 步驟

1. 打開終端機，貼上下面兩行並按 Enter：

   ```bash
   cd /Users/jackhsieh/Downloads/TUD/Q5/project
   .venv/bin/python scripts/e2_formal_run.py
   ```

2. 腳本會依序做 6 步，每一步都先問你，輸入 `y` 才繼續；輸入其他鍵就中止，不會送出那一步。

| 步驟 | 內容 | 需要密語 |
|---|---|---|
| 1 | 建立天氣資料快照（E2 使用的天氣推導方法 candidate-01） | 否 |
| 2 | **批准天氣資料快照** | **是** |
| — | 自動做方法驗證（Ladybug／Radiance 對同一天氣的一致性檢查） | 否 |
| 3 | **選基準方案**：輸入 1＝common-compact（緊湊）或 2＝common-mixed（混合），再打一句接受理由 | **是** |
| 4 | 建立實驗計畫（6–8 月、5 m 地面網格、±1 小時敏感度） | 否 |
| 5 | **批准實驗計畫** | **是** |
| 6 | 開始計算（只派送一次，約數分鐘到數十分鐘），完成後自動做比較 | 否 |

3. 看到「✓ E2 完成」就好了，跟我說「E2 跑完了」，我會檢查結果、更新報告與平台。

## 如果出錯

- 腳本印出「決策未成立」：通常是密語打錯，重新執行腳本即可（前面已完成的快照會重新建立一份新的，不影響正式紀錄的正確性）。
- 腳本印出「計算結果不明或失敗，請不要重跑」：**不要再執行**，直接告訴我，我會用 job 紀錄對帳；系統規則是結果不明時絕不自動重送。
- 任何其他錯誤：把終端機畫面整段貼給我。
