# W5-12 天氣推導方法一頁摘要

**狀態：** 提案，等待設計者決定；沒有發布 DatasetSnapshot，沒有開始氣候實驗，網路請求數為 0。原始 R08 bytes 僅唯讀。  
**提案包：** [修正版 proposal](../../artifacts/w5-weather-derived-method-proposal-20260926T115309Z/manifest.json)；[首次計算（已標記取代）](../../artifacts/w5-weather-derived-method-proposal-20260926T114957Z/manifest.json)。首次計算因 Ladybug `Location` 參數位置錯誤，把站點讀成約 1°N、−4.5°E；沒有用於本摘要。保留它作為可追溯的錯誤嘗試，不修改 R08。

## 方法與資料邊界

- R08 保留三個 Rotterdam TMYx EPW，各 8,760 筆、Minute 欄均為 0。使用 EPW LOCATION 中緯度、經度、時區與高度，以具名參數建構 Ladybug `Location`，再用 Ladybug `Sunpath` 分別按小時終點、起點、中點算太陽高度。
- 「DNI > 0、太陽高度 < 0」計數標記 **DATASET_OBSERVATION + INFERENCE**：DNI 是保留檔欄位觀察；太陽高度是 Ladybug 對時間假設的推導。此結果不是供應商時間語義證據。
- 推導副本只改每列 Minute：`0 → 60`，詮釋為該小時終點；逐列 CSV 同時記錄原列與推導列 SHA-256，可逐列還原原始 bytes。推導檔全數通過未修改的 `_epw_metadata` chronology validator。
- `summer_direct_radiation_sensitivity` 是 6–8 月 DNI 乘 Ladybug 太陽方向和四個平面正入射餘弦的純 Python 篩選結果，單位 kWh/m²。南、東、西是垂直面；水平面亦計算。沒有 Radiance、遮蔽、漫射、反射、情境幾何或 E2 感測點。
