# 德國 BauNVO（The German BauNVO Zoning and Land Use Ordinance）
領域：REG｜相關細卡：KU-REG-007, KU-REG-013, KU-REG-015, KU-REG-016, KU-REG-017, KU-REG-018, KU-REG-019, KU-REG-020, KU-REG-021, KU-REG-061, KU-REG-062, KU-REG-063, KU-REG-064, KU-REG-065, KU-REG-066, KU-REG-503

## 一句話
德國聯邦建築利用條例（BauNVO）透過全國統一的土地用途目錄與建蔽容積指導值矩陣，建立了地方自治體編制具法律約束力建設規劃的嚴謹骨架，並以高度包容的混合導向區別於美式排他分區。

## 核心概念與定義
《聯邦建築利用條例》（Baunutzungsverordnung / BauNVO）是德國聯邦空間規劃法規體系的核心實施細則（BAUNVO, KU-REG-015）：
1. **法規位階與規劃架構**：
   - 上位法為《聯邦建設法典》（Baugesetzbuch / BauGB）；
   - 市鎮地方編制兩級計畫：宏觀預備性「土地利用規劃（Flächennutzungsplan / FNP）」與微觀地塊級具法律約束力的「建設規劃（Bebauungsplan / B-Plan）」（KU-REG-015, KU-REG-027）；
   - BauNVO 為全德國 B-Plan 提供統一的「用途區分類（Bauflächen und Baugebiete）」與「建築密度量測尺度（Maß der baulichen Nutzung）」（BAUNVO, KU-REG-503）。
2. **核心建築密度指標（Maßzahlen）**：
   - **GRZ（Grundflächenzahl / 建蔽率）**：建築底層佔地面積與地塊面積之比（$GRZ = \text{建築基底} / \text{地塊面積}$）（KU-REG-015）。
   - **GFZ（Geschossflächenzahl / 容積率）**：各層總樓地板面積與地塊面積之比（$GFZ = \text{總樓地板} / \text{地塊面積}$）（KU-REG-015）。
   - **BMZ（Baumassenzahl / 立方量指數）**：建築地上總實體積立方米與地塊面積平方公尺之比（$m^3 / m^2$），主要用於工業與商業倉儲區（GE/GI）（BAUNVO, KU-REG-066）。
3. **主要用途地域（Baugebiete）與 §17 指導值（Orientierungswerte）**：
   - **WR / WS（純住宅區 / 小型定居區）**：GRZ 0.4 / GFZ 1.2（KU-REG-061）。
   - **WA（一般住宅區，Allgemeines Wohngebiet）**：允許小型非干擾性商業與店舖；GRZ 0.4 / GFZ 1.2（KU-REG-062）。
   - **WB / MI（特別住宅區 / 混合區，Mischgebiet）**：居住與無干擾商業實質等權並重；GRZ 0.6 / GFZ 1.2–1.6（KU-REG-063）。
   - **MU（都會區，Urbanes Gebiet，2017 年新修訂 §6a）**：專為高密度混合街區設立，允許較高噪音容忍度；GRZ 0.8 / GFZ 3.0（KU-REG-064, KU-REG-503）。
   - **MK（核心商業區，Kerngebiet）**：市中心高強度商業區；GRZ 1.0 / GFZ 3.0（KU-REG-065）。
   - **GE / GI（商業區 / 工業區，Gewerbe- und Industriegebiet）**：GRZ 0.8 / GFZ 2.4 / BMZ 9.0（KU-REG-066）。
4. **2021 年重大修法轉折**：2021 年 BauNVO 修正案明確將 §17 數值定義為「指導值（Orientierungswerte）」而非以往各自治體不可逾越的「剛性上限（Höchstgrenzen）」，賦予地方在考量氣候適應與大眾運輸時彈性突破的裁量權（BAUNVO, KU-REG-015, KU-REG-503）。

## 主要立場與學派
1. **法治國家與確定性規劃學派（Rechtsstaatlichkeit / 德國傳統公法學派）**：主張土地開發權必須由嚴格的成文法典與標準化目錄嚴密控制，確保任何公民與開發商均能獲得高度法律可預測性，反對英美式的自由自由裁量交易（HIRT2010, KU-REG-015）。
2. **行政程序實效實證學派（Oliver Dillmann & Volker Beckmann，2018）**：運用實證計量檢驗德國空間法規簡化政策（如 §13a BauGB 內城加速程序），指出單純簡化行政程序並不能自動逆轉土地市場區位偏好（DILLMANN2018, KU-REG-007, KU-REG-020）。

3. **對主流論點的批評**：不得以本輪文獻摘要作為當前 BauNVO 法規判讀。 [KU-REG-019]
## 關鍵證據與數字
- **美德分區容許度對比（Sonia Hirt 2010）**：與美國將公寓與商業視為住宅「病毒」不同，德國最普遍的 WA 一般住宅區中，法律明確保障小型麵包坊、診所、律師事務所與公共圖書館作為「原則性准許項目（Regelzulässige Nutzungen）」，體現了深刻的社會包容傳統（HIRT2010, KU-REG-013）。
- **內城加速程序（§13a BauGB）實證成效（Dillmann & Beckmann 2018）**：對德國數百個市鎮實證追蹤發現，透過 §13a 免除環評以加速內城棕地開發的措施，使規劃審批週期平均縮短 4–6 個月，但對刺激外圍資本回流內城的實際新增建築面積邊際貢獻不足 5%（DILLMANN2018, KU-REG-020）。
- **MU 都會區容積與覆蓋上限躍升**：相較於傳統 MI 混合區的 GRZ 0.6 / GFZ 1.2，2017 年新設的 MU 都市區直接將指標拉升至 GRZ 0.8 / GFZ 3.0，使街廓最大可建容量暴增 2.5 倍，為德國回歸 19 世紀末高密度混合街廓提供了現代法規依據（KU-REG-064, KU-REG-503）。

## 爭議與批評
傳統主義批評者指出，BauNVO 的類別定義依然帶有二十世紀中葉的「機械分類殘留」：例如將手工作坊、物流分撥與文化排練場劃入不同類別，導致許多新興的數位製造與共享工坊在報批時找不到對應欄位，被迫陷入漫長的法律訴訟（KU-REG-019）。此外，雖然聯邦法律鼓勵混合，但地方市鎮出於招商政績考量，仍習慣大片劃設 GE 商業園區以追求營業稅（Gewerbesteuer），導致實際空間依舊陷入功能隔離（KU-REG-021）。

## 設計應用：在新開發區怎麼用、何時不適用
- **在新開發區怎麼用**：設計借鑑德國制度時，新城核心生活街廓應優先採用「MU（都會區）」或「WB/MI（混合區）」原型編制規劃圖則：設定 GRZ 0.6–0.7、GFZ 2.0–2.8；在用途欄位中，將「無實質公害之輕型創客與店面」設為「原則性准許」，並在建築剖面中明定底層淨高不得低於 4.0 米（KU-REG-017, KU-REG-064）。同時在條款中載明：當開發方案採用被動式超低能耗綠建築或提供公共托兒所時，允許 GFZ 依照 §17 指導值向上浮動 20%（KU-REG-015, KU-REG-503）。
- **何時不適用**：移植到不同法域或條例修訂中的開發案時，需核對現行法規、審批程序與執行主體；其他國家的分區分類不能直接當成本地規則。

## 常見錯誤
1. **將 §17 指導值誤當成全國死門檻**：忽視 2021 年修法後 §17 數值已轉化為 Orientierungswerte，不知地方政府只要提出充分的日照通風分析與交通承載評估，即具備法定權限予以超越（BAUNVO, KU-REG-015）。
2. **生搬硬套德國縮寫符號**：在不具備德國 BauGB 司法救濟體系的海外專案中，只把「WA、MI、GE」抄在總平面圖上，卻沒有相應的容許用途清單與隔音驗收條例，使管制成為文字遊戲（KU-REG-017, KU-REG-060）。
