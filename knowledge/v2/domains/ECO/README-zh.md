# ECO｜都市生態與生物多樣性

都市生態研究城市如何改變棲地、物種和生態過程，也研究規劃與管理如何介入這些變化。生態不只是公園裡的綠色面積：樹冠、土壤、水系、廊道、建築和城市消費共同構成不同尺度的生態條件。設計者要先說清楚想保護的物種、過程或生態系統服務，再選擇合適的指標。

## 十個重要發現

1. **棲地面積和廊道常是都市生物多樣性的重要條件。**涵蓋七十五座城市的統合分析指出，斑塊面積與廊道對多個分類群呈較強正向作用；植被結構也會影響結果，跨城市平均不能直接變成基地處方。
2. **大斑塊與小綠地服務不同生態尺度。**研究回顧指出，超過五十公頃的場址對避免面積敏感物種快速流失可能重要；小型綠地仍可支援局部物種、步行和日常自然接觸。
3. **城市物種豐度與城市化程度有關，物種身份同樣重要。**全球多城市資料估計都市內本地鳥類與植物密度約為非都市估計的百分之八和百分之二十五；樣本及城市差異限制這些比例的外推。
4. **樹冠降溫受局部尺度與覆蓋率共同影響。**美國中西部一座城市的夏季路線量測發現，樹冠超過百分之四十時降溫較大，街廓六十至九十公尺尺度的變化最明顯。該結果不是跨季節或所有氣候的保證。
5. **土地分享與土地保留不會對所有類群給出同一答案。**東京蝴蝶和步甲研究在高度都市化下多支持土地保留，在較低都市化時兩類昆蟲反應分歧。景觀策略須按目標生物和城市化背景選擇。
6. **緊湊與蔓延發展都可能造成生境損失，但空間分布不同。**Brisbane 模型比較八萬四千六百四十二戶住宅增長，兩種成長均降低鳥類分布；緊湊方案在全市尺度較能放慢損失並保留大型綠地，模型仍受輸入與情境假設約束。
7. **生物多樣性管理離不開治理和文化。**都市綠地回顧指出，維護、土地決策、偏好和社會網絡會左右實際保育成果，不能把管理壓縮成植物名單。
8. **外來種或新型都市生態不應先被判為無價值。**保育評估需要觀察物種、功能與演替證據，同時管理入侵風險與本地生境需求。
9. **樹木的熱、水和空氣效益依位置及維護改變。**樹種、冠幅、土壤、季節和街道幾何都會影響服務；同一植樹數量不代表相同的遮蔭或降溫成果。
10. **生態系統服務的總量不會揭示受益者和取捨。**滯洪、降溫、休閒與生境可在同一方案並存，但效益可能分布於不同地點和群體，還會與照明、噪音或土地價值變化交互作用。

## 學派與爭議

經典地景生態以斑塊、廊道和基質描述空間結構；城市生態則研究城市化、社會—生態系統和跨尺度物質流。都市保育工作將物種與棲地保護帶入規劃；生態系統服務框架便於跨部門討論效益，卻可能把生態價值商品化並忽略權利分配。自然為本解決方案和綠色基礎設施著重多功能調適，但其成效取決於地方生態、維護、治理與住房背景。

主要爭議包括土地分享與保留策略、原生種優先與新型生態系價值、廊道是否可能傳遞入侵種或干擾、樹木降溫效應的可轉移性，以及將非人類生命折算為貨幣是否合宜。所有數值都應連回研究設計、區域、分類群和量測尺度；來源限制不得被轉寫成普遍設計規範。

## 對設計的意義

以生態問題而非「增加綠量」作為起點：目標物種是誰？需要的是繁殖地、移動通道、樹冠連續、降雨調節還是熱暴露降低？先建立基線和管理情境，再安排嵌塊、廊道、樹木及人類活動。研究中的百分比、距離和面積只是特定情境的證據，不能取代本地生態調查。方案應說明維護、監測、使用衝突和受益分布，並為後續修正保留條件。
