# HOU｜住宅與鄰里：給設計者的導讀

## 研究對象
住宅類型包含戶型、樓層、入口、產權、服務和共同空間；戶數／公頃和室內面積只描述其中部分。社會住宅、混合產權和鄰里單元亦是制度與治理安排，不是單一建築外觀。

## 十個要點

1. 獨棟、半獨立、連棟、walk-up、周邊式和點式住宅具有不同的戶數密度與公共空間結構；密度比較必須分清淨地和毛地分母。
2. 本庫新增的類型帶包含獨棟約 10–25 戶／ha、連棟約 35–70 戶／ha、周邊式中層約 80–180 戶／ha、高層點式約 150–350 戶／ha；全部是待核對的方案比較範圍，不是建築標準。
3. studio、1 房、2 房與家庭戶型面積要和收納、照護、居家工作及共享設施一起比較。
4. 斯德哥爾摩學生住宅研究中，廚房、清潔和交通可及性是滿意度的重要預測因素；studio 和走廊房結果不能直接推廣到家庭住宅。
5. 孟買安置住宅研究涵蓋 981 戶，室內條件、社區環境和設施接近都與居住滿意相關。
6. 荷蘭 woningcorporaties 社會租賃存量比例在歷史比較中約 28–35% 的量級；必須隨年份和社會住宅定義一起引用。
7. 加拿大社會住宅政策史顯示不同補助和所有權制度可形成相近的低收入可負擔供給；政策形式不能只按國名分類。
8. 多倫多收入計租條目的現有摘要寫有租戶比例與相對市場租金的數值關係，但精確口徑仍待指揮官核對；不能轉用為當代政策成效。
9. Perry 的鄰里單元常以約 160 acres、四分之一英里服務尺度和小學中心來重述；學校服務圈不等於今日居民認同或完整服務機會。
10. 高齡住宅研究指出安全、熱舒適、無障礙和日常服務共同影響在地老化；代間共居的設計可能性不能代替照護成效證據。

## 學派與爭議
住房政策研究比較社會住宅、補助和市場供應；都市形態研究分析住宅類型、密度和街區；鄰里研究則檢驗形式與地方依附、福祉之間的中介條件。空間混合不會自動消除不平等，住宅交付也不等於服務品質或可負擔性。

## 對設計的用法
先聲明戶數／ha 分母、單元面積口徑和目標住戶，再比對樓層、戶型、出入口、公共空間、交通與社會管理。荷蘭存量比例、住宅密度、戶型面積與歷史政策數值均標為待指揮官交叉核對；不能當成本基地配額或法規。
