# MOR｜都市形態與類型學：給設計者的導讀

## 研究對象
都市形態學把街道、地塊、建築、開放空間和土地使用當成相互作用、但變化速度不同的層次。它既能描述一個地方如何形成，也能比較同一密度如何由不同的街廓和建築型態實現。FSI、GSI、OSR 和平均層數 L 是比較工具，不是型態品質評分。

## 十個要點

1. Conzen 的 town-plan analysis 分讀街道系統、地塊系統和建築地帶；plan unit 能將不同歷史層次放在同一圖面。
2. burgage cycle 追蹤狹長地塊由臨街建築向後院逐步加密，再因合併、改建或經濟轉變而重組。
3. fringe belt 常在城市外緣擴張停頓時形成，墓園、公共設施或大型工業用地會留下難以切分的邊緣帶。
4. Muratori／Caniggia 把建築類型視為在日常建造中延續、變異的過程，不只是一張立面分類表。
5. Spacematrix 的 FSI=總樓地板量／範圍面積，GSI=建築覆蓋／範圍面積；L=FSI/GSI。OSR 把未建空間和樓地板量連起來，計算時必須聲明分母。
6. 同一 FSI 可以由低層高覆蓋、周邊式街廓或高層點式組合實現；高度、覆蓋、內院和路網要一起比較。
7. 已納入待核對的歷史街廓例子包含巴塞隆納 Eixample 約 113 m 模數、波特蘭約 61 m 方格、芝加哥約 100×200 m 長方格及阿姆斯特丹運河屋約 5–8 m 面寬。這些是歷史形態參考，不是通用設計標準。
8. 全球城市形態研究能同時找到區域內相似型和跨區域相似型，不能把歐洲、亞洲簡化為兩種固定模式。
9. 形態指標對地塊邊界、道路是否進分母、地下層和用途計入敏感；兩個相同 FSI 的地方可能有完全不同的開放空間。
10. Lynch 的 paths、edges、districts、nodes、landmarks 描述城市可讀性；Alexander 的小廣場、街邊咖啡座和活動口袋則是可被測試的公共空間模式。

## 學派與爭議
英國城鎮平面學關注歷史層次和地塊慣性；義大利類型形態學關注建築類型如何在時間中轉變；荷蘭 Spacematrix 把密度拆成可比較變數；網絡研究則將街道配置和移動機會放進分析。Ratti 對 Space Syntax 測量提出批評，後續研究亦指出角度距離、網絡尺度和活動吸引力都會改變解釋。形態相關不能直接證明社會或能源因果。

## 對設計的用法
先固定街道、宗地、街廓與基地的分析邊界，再計算指標。把地面開放空間、建築深度、入口頻度、可穿越路徑和管理權一起列出。歷史尺度和 Spacematrix 類型區間目前標為 `CANONICAL_CROSS_CHECK_PENDING`，指揮官核對前只能作比較假設；不確定數字應刪除或改為定性描述。
