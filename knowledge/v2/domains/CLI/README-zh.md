# 都市氣候、日照、風與熱（CLI）｜研究導讀

## 這個領域在問什麼

CLI 研究街道幾何、建築、材料、植栽和天氣如何共同改變輻射、氣流、溫度及戶外活動感受。它要求分清行人高度空氣溫度、地表溫度、風速、日照和人體熱舒適等不同量。本版收錄 **72 個單元，其中 23 個數值範圍**；跨城市的數字只能當比較線索，不能取代基地模擬、量測或法規審查。

## 十項重要發現

1. **H/W 是形態指標，不是設計答案。** 街谷高寬比須和方位、天空開敞度、來風及氣候一起閱讀。本庫把 0.5 與 2 左右作為淺谷／深谷的經典對照，並標為 `CANONICAL_CROSS_CHECK_PENDING`。
2. **天空可視因子描述幾何開敞。** SVF 的 0–1 範圍表示可見天空比例；它能協助比較遮蔽和夜間散熱條件，但不能單獨預測熱舒適。
3. **都市熱島依量測方式而變。** 近地空氣、城市冠層和衛星地表溫度不是同一指標；夜間城市—郊區差值的 0–10°C 量級是經典範圍，仍待交叉核對，不能移用成所有地點的預測值（Arnfield，2003；Stewart 與 Oke，2012）。
4. **Lawson 風舒適分類連結風速與活動。** 傳統版本常見坐姿、站立、漫步和步行的 2、4、6、8 m/s 門檻；平均時距、陣風、超越頻率和準則版本都會影響判定，目前仍標待交叉核對（Blocken 等，2016）。
5. **日照準則各自量不同事物。** 倫敦市政府 Housing Design 草案列出臥室與客廳 ADF 建議值，並提出春分戶外日照檢查；該頁稱 BRE 預設值為 advisory，應視為草案建議，不能當作英國全國法規或 M4H 要求。[GLA Housing Design](https://www.london.gov.uk/publications/housing-design)
6. **樹蔭覆蓋率不等於降溫幅度。** 綠化系統性回顧支持降溫方向，但不同研究量測空氣、地表或人體熱感，效果量不能混用。現有證據尚不足以給 M4H 可直接採用的樹冠降溫數字（Bowler 等，2010）。
7. **反照率是材料輻射參數。** 0–1 表示反射能量比例；較高反照率可能改變能量收支，但表面溫度和行人舒適仍受濕度、粗糙度、遮蔭及街谷交換影響（Santamouris，2014；Yang 等，2016）。
8. **PET 與 UTCI 是標準化熱壓力指標。** 典型分類帶提供不同研究間的共同語言，並不代表所有氣候居民的主觀舒適界線；本庫列出的分級數值均保留交叉核對標記（Matzarakis 等，1999；Bröde 等，2012）。
9. **高密度形態帶來多重權衡。** 建築高度和街谷深度會影響遮蔭、風交換、日照與戶外活動，單一形態參數無法同時最佳化所有性能（Ng，2009；Ali-Toudert 與 Mayer，2006）。
10. **模型需要和觀測一起驗證。** 風洞、CFD、現地測站和遙測各有尺度與邊界條件；模擬結果須保留網格、邊界風況、材料狀態和驗證紀錄（Blocken 等，2016；Arnfield，2003）。

## 主要學派與爭議

都市氣候物理研究強調能量、水分和空氣交換；形態研究把 H/W、SVF 和方向轉為可分析參數；適應性舒適研究加入活動、衣著和個人經驗。爭議包括通用舒適分級是否掩蓋地域適應、模型解析度能否支援街道決策，以及樹木或高反照率材料的局部冷卻是否會帶來水耗、眩光或風環境代價。標準化有利於比較，但不能取代地方使用者和實測資料。

## 對設計的意義與仍待補證之處

方案比較應同步標出季節、時段、測量高度、天氣邊界、街谷幾何、植栽狀態與人體參數。圖面不要把陰影、空氣溫度、地表溫度和熱舒適合併成單一「降溫」值。H/W、Lawson、PET、UTCI、UHI 與反照率的經典數值保留待核對標記；跨城市樹木降溫幅度與 M4H 的風、日照和熱暴露仍需實測或模型驗證。
