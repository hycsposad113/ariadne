# SYN｜空間語法與網路分析：給設計者的導讀

空間語法和城市網路分析把街道、軸線、路段、交點與目的地轉成可比較的圖。整合度、選擇度、多中心性和角度／度量成本描述不同關係；它們不是人流、品質或公平的直接替代值。分析結果依賴邊界、路網表示、距離、半徑和資料完整度，必須公開假設。

## 十個重要研究發現與設計提醒

1. Sharmin 與 Kamruzzaman 的 1975–2016 隨機效果統合分析中，整體整合度與行人移動的合併效果為 ES 0.206（95% CI 0.173–0.238）；研究間差異高，這不是人數或預測係數（SHARMIN17）。
2. 同一分析按表示方式分組，角度整合度 ES 0.502，拓樸整合度 0.124；表示方式會改變關聯量級（SHARMIN17）。
3. 角度選擇度 ES 0.493，拓樸選擇度 ES 0.374；兩者反映不同路徑成本，不是同一量尺（SHARMIN17）。
4. 統合分析中的連通度 ES -0.001（95% CI -0.117–0.115，p=0.990），沒有顯著行人移動關聯；可計算不代表有解釋力（SHARMIN17）。
5. 高度異質性表示圖表示、尺度、樣本與研究設計都會影響關聯；應報告指標、半徑和參數，而非只呈現色階（SHARMIN17）。
6. Hillier 等人的自然移動論述把街網組態視為穿越移動條件，並指出零售可能放大人流；這不保證跨城市因果（HILLIER93）。
7. 孟加拉 Mymensingh 街段研究中，組態與行人量關係偏弱，商業用途提供較強線索，提醒把目的地資料放入分析（AZIZ2018）。
8. 荷蘭三個新城與一個舊城比較顯示，舊城在整合、建築密度和用途混合指標較高；小樣本不能識別單一因素的因果效果（YE14）。
9. Porta 等人的 primal 圖多中心性研究可比較街網骨架，並辨識其樣本中的規劃型與自組織網路差異；方法仍受圖表示和樣本限制（PORTA06）。
10. Ratti 對空間語法幾何處理的批評與 Hillier、Penn 的回應構成方法辯論；論文沒有替任何方法在所有用途上判勝負（RATTI04；HILLIERPENN04）。

## 經典概念與分析尺度

自然移動論述先問街網如何分配可能的穿越路徑；movement economy 再加入沿線活動吸引人流、而人流又影響活動分布的回饋。兩者都需要和土地使用、人流計數及時間順序一起檢驗。R3 是三個拓樸步驟的局部情境，Rn 指向連通圖的全域範圍；角度成本、拓樸步數和公尺距離是不同路徑成本。400、800、1,200 m 單元是可替換的敏感度情境，不代表空間語法標準半徑。軸線、線段與 primal graph 也保留不同的幾何和連接資訊。

Lynch 的五種城市意象要素是路徑、邊界、區域、節點和地標。Place Syntax 的確切候選書目未能以允許的書目 API 命中，因此本批只保留目的地敏感的可及性概念，未宣稱核實特定軟體流程或權重方法。所有分析尺度都不是基地規範；正式比較須公開底圖、邊界、圖表示和成本設定。

## 學派、地域與爭議

本領域包含 Hillier 與 Hanson 的空間語法、角度線段分析、Porta 等人的 primal network science、多中心性、GIS 可及性，以及 Ratti 對圖形與幾何處理的批評。它們回答的問題不同，不能直接排名。英國理論和歐洲案例較常見；本批同時納入孟加拉、哥倫比亞、巴西和亞洲城市研究，提示街網關係受用途、地形、制度和資料覆蓋影響。特定 Place Syntax 工具的精確書目未查獲，因此本批只涵蓋目的地敏感的網路可及性概念，不假稱已驗證工具名稱或實作。

## 對設計的意義

把網路分析當成可反駁的假說：凍結底圖、節點和線段規則、邊界、尺度與成本，再做替代表示的敏感度比較。分開呈現整合度、選擇度、度量距離、目的地可及性和實際人流，並以現場資料、可通行性與公共生活核對。分析找出候選路徑後，仍由設計者和社群判斷其公共角色。

課綱對應 TU Delft 的 Methods of Analysis & Imagination、Harvard GSD 的 Cities by Design、MIT 的 Theory of City Form，以及 UCL Bartlett 的 Critical Debates in Urban Design。
