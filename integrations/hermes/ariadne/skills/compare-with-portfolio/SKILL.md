# 與原設計比較（Compare with Portfolio）

將當前生成或微調中的設計方案，與設計者 Jack 既有的 Q2 Urbanism Portfolio 原設計基準（`urbanism-q2-portfolio.pdf`）進行多維度指標與空間原則對照。

## 相關 MCP 工具

- `list_scenarios`：列出所有候選方案並取得 Portfolio 原設計基準概要。
- `compare_scenarios`：產出多方案與原設計基準的比較矩陣與結構化分析。

## 對照關鍵維度

1. **容積率（FAR）與量體密度**：
   - Jack 原設計基準目標 FAR 約為 **2.85**。
   - 檢視新方案是否過密或過疏，並評估總建築樓地板面積分佈。
2. **水岸開放性與 15m 親水公共帶**：
   - Jack 原設計要求沿 Merwehaven 設置至少 **15 m 連續親水步行走廊**。
   - 檢視各方案在水岸第一排的建築退縮與視野通透度。
3. **既有工業建築處分（Adaptive Reuse）**：
   - 原設計著眼於 Gusto 船廠舊址與周邊大型物流倉庫之再利用。
   - 檢視方案是否有過度拆除或破壞歷史紋理之虞。
